# Saique · Atelier

Identidad editorial de alfombras: paisaje de arenisca, textura de tejido, tipografía serif de gran escala, superficie marfil y verde profundo. Se retiró Aladdín por petición del usuario.

El acceso usa un fondo panorámico generado, desplazamiento suave por cursor, entrada breve del título y formulario accesible. Pausa de movimiento, reducción de animación del sistema y liberación de recursos al desmontar. Sin dependencias gráficas añadidas. El paisaje es una imagen con movimiento por capas, no un modelo 3D.

La identidad se extiende a navegación, tablas, formularios y tarjetas de los 14 módulos. La lógica de permisos y operaciones se conserva.

Criterios consultados: Emil Kowalski (movimiento y respuesta), Impeccable (jerarquía y revisión) y Taste (coherencia). Figma MCP no está conectado; no se afirma haberlo utilizado. Playwright del navegador conectado se utiliza para inspeccionar el acceso.
